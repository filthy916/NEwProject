Safety notes

Disclaimers and footnotes

Disclaimers

  • The secret is stored only in a transient JavaScript variable and is not written to localStorage, sessionStorage, or cookies.
  • 1ONE sends a single POST request to /api/bridge and does not maintain a multi-turn conversation log.
  • Responses are displayed as received. If the backend returns an error, the UI will surface the status and payload directly.

Footnotes

  1. In-memory auth means the page forgets the secret on refresh, tab close, or a full reload.
  2. The bridge payload is intentionally minimal so the backend can decide how much to accept or ignore.
  3. If the endpoint expects a different field contract, the request body can be adjusted without changing the rest of the UI.
